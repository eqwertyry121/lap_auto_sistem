Вот итоговый, максимально подробный и структурированный **технический ТЗ-план**. Его можно прямо в таком виде скормить **Qwen 3.8 Preview** в качестве системного промпта для разработки.

## 🛠 Технологический стек

- **Язык разработки:** Go (Golang)
    
- **База данных (Состояние и истории):** PostgreSQL
    
- **База рыночных цен и аналитики:** Google Sheets API
    
- **Уведомления и интерфейс:** Telegram Bot API
    
- **ИИ (Анализ текста, Vision, Ресерч):** Gemini API
    
- **Целевая платформа:** KupujemProdajem (KP)
    

## 📋 Итоговый пайплайн системы (Step-by-Step)

```
[Cron: каждые 2-3 мин]
       │
       ▼
1. Сбор ID объявлений с KP
       │
       ▼
2. Сверка с PostgreSQL (Фильтр дублей) + Запись ВСЕХ лотов в Google Sheets (База рынка)
       │
       ▼
3. Фильтрация спама / магазинов
       │
       ▼
4. ФАЗА 1: Текстовый анализ (Gemini Text + Кэш цен)
       ├── Есть 100% профит ──────────────► [Telegram ALERT]
       ├── Непонятный / Новы лот ────────► [Telegram NEED CHECK]
       └── Нет характеристик/модели ────► ФАЗА 2: Vision по фото (Gemini Vision)
                                                ├── Модель найдена ──► Ресерч ──► [Telegram ALERT]
                                                └── Модели НЕТ на фото
                                                         │
                                                         ▼
                                                   ФАЗА 3: Авто-сообщение продавцу (Сербский)
                                                   + Пометка в DB: WAITING_SELLER_REPLY
                                                         │
                                                         ▼
                                                   ФАЗА 4: Воркер ответов
                                                   └── Пришла наклейка ──► Vision ──► [Telegram ALERT]
```

## 🔍 Детальный разбор каждого шага

### Шаг 1. Мониторинг и Скрапинг (KP Collector)

- **Периодичность:** Запуск каждые 2–3 минуты.
    
- **Логика:** Парсер забирает первую страницу категории ноутбуков.
    
- **Выход:** Список свежих ID, заголовков, цен и ссылок.
    

### Шаг 2. Дедупликация и Сбор рыночной базы (Postgres + Google Sheets)

- **PostgreSQL:** Проверяет ID. Если лот уже есть в базе — он пропускается. Новые лоты заносятся со статусом `NEW`.
    
- **Google Sheets (Live Market):** **Каждое новое объявление** (даже хлам или оверпрайс) записывается в отдельную вкладку `Market_History` (Дата, Заголовок, Цена, Валюта, Ссылка). Это формирует статистику средних цен.
    

### Шаг 3. Фильтрация спама и магазинов

- Отсеивание коммерческих аккаунтов (по ключевым словам в имени продавца: _Store, Shop, DOO, Laptop Centar_).
    
- Отсеивание партий (если в заголовке указано _«Na stanju 10 komada»_).
    

### Шаг 4. Фаза 1 — Текстовый анализ и оценка (Gemini Text)

- **Кэш цен:** Go-сервис держит в памяти таблицу рыночных цен из Google Sheets (обновляется раз в 30 мин).
    
- **Сравнение:** Gemini получает текст + рыночную вилку из таблицы.
    
    - **Профитный лот:** Отправляет мгновенный `ALERT` в Telegram.
        
    - **Сомнительный/Новый девайс:** Отправляет `NEED CHECK` в Telegram.
        
    - **Нет описания/модели:** Передаёт объявление на **Шаг 5**.
        

### Шаг 5. Фаза 2 — Vision-анализ фото (Gemini Vision)

- Загружаются до 5 фотографий из объявления.
    
- Gemini Vision ищет наклейки, гравировки, шильдики или определяет корпус.
    
    - **Модель найдена:** Выполняется ресерч железа $\rightarrow$ сравнивается с рынком $\rightarrow$ присылает `ALERT`.
        
    - **Модель НЕ найдена:** Передаёт объявление на **Шаг 6**.
        

### Шаг 6. Фаза 3 — Авто-отклик продавцу (Сербский язык)

- Скрипт через сохранённую авторизованную сессию KP отправляет продавцу в ЛС:
    
    > _"Zdravo! Zainteresovan sam za kupovinu. Da li možete da mi pošaljete čistu sliku nalepnice sa dna laptopa gde se vidi tačan model? Hvala!"_
    
- В PostgreSQL статус объявления меняется на `WAITING_SELLER_REPLY`.
    

### Шаг 7. Фаза 4 — Воркер входящих сообщений (Reply Worker)

- Фоновый процесс раз в 5–10 минут проверяет входящие сообщения на KP.
    
- Когда продавец присылает изображение, бот забирает фото $\rightarrow$ прогоняет через Gemini Vision $\rightarrow$ делает финальную оценку $\rightarrow$ отправляет вам `ALERT` со всей историей.
